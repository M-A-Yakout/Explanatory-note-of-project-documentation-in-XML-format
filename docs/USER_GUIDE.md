Эксперт видит данные только для чтения, кнопок изменения у него нет. Свою роль менять и себя блокировать нельзя; у организации всегда остаётся хотя бы один активный администратор.

## Как подготовить пояснительную записку

1. **Объекты → Новый объект.** Наименование, адрес, кадастровый номер (формат `77:01:0004012:1234`), вид строительства, застройщик.
2. **Пояснительные записки → Новый документ** (или **Импорт XML**). Выберите объект и версию схемы (по умолчанию — актуальная). Данные объекта подставятся сами.
3. **Редактор.** Пять разделов слева, шкала заполнения сверху:
   * *Титульные данные* — поля со звёздочкой обязательны;
   * *ТЭП* — таблица показателей (можно добавить «типовые»); числа в любом виде: `8 412,0` будет записано как `8412.0`;
   * *Состав проектной документации* — отметьте включённые разделы;
   * *Нормативные ссылки* — из каталога или свои;
   * *Дополнительные сведения* — свободный текст.
   Изменения **сохраняются автоматически** (индикатор «Сохранено 14:32»). Если тот же документ изменён в другом окне, редактор предложит загрузить актуальную версию — чужие правки не затираются.
4. **Проверить.** Откроется список замечаний: ошибки блокируют выгрузку, предупреждения — нет (если администратор не включил запрет). Рядом с замечанием — «Перейти к полю». Числа у разделов в редакторе показывают, где ошибки.
5. **Просмотр XML** — дерево или исходный текст, поиск, копирование, рядом — читаемый вид документа.
6. **Выгрузка.** Кнопка «Скачать XML» доступна, если ошибок нет. Сервер перепроверяет документ в момент скачивания.

**Версии.** «Сохранить версию» фиксирует состояние с комментарием. На странице версий можно сравнить любые две версии (или версию с текущим состоянием) и восстановить старую — восстановление записывается как новая версия, ничего не теряется.

## Импорт готового XML

Загрузите файл (UTF-8 или windows-1251) → сервис покажет отчёт: сколько перенесено, **что не перенесено** (с путём в файле и причиной), что обрезано и какие замечания к файлу есть по XSD. Если версия схемы из файла недоступна, будет использована схема по умолчанию (об этом предупредят). Затем «Создать документ» — дальше обычная работа.

## Архив

«В архив» — документ пропадает из основного списка и становится доступен только для чтения. На странице **Архив** — восстановление (возвращается прежний статус) и окончательное удаление (администратор, с подтверждением). В списке документов можно отметить несколько и отправить в архив или скачать их XML одним ZIP (в архив попадут только прошедшие проверку; остальные перечислены в `_skipped.txt`).

## Администратору организации

* **Пользователи → Пригласить**: укажите почту и роль; человек получит ссылку (действует 7 дней) и сам задаст имя и пароль. Можно отправить снова или отозвать.
* **Заблокировать** — доступ пропадает сразу, действующие сессии прекращаются. **Сбросить пароль** отправляет человеку ссылку для установки нового.
* **Журнал аудита** — кто и что делал; фильтры, поиск, выгрузка в CSV (для Excel).

## Супер-администратору

* **Организации**: создание, лимиты пользователей и объектов, отключение (все её пользователи сразу теряют доступ).
* **XML-схемы**: загрузка XSD (проверяется при загрузке), активация/отключение, схема по умолчанию, структура схемы, скачивание. Используемую схему удалить нельзя — только отключить.
* **Настройки системы**: запрет выгрузки при предупреждениях, правило об устаревших ссылках, максимальный размер XML, подтверждение почты, шаблоны писем.
